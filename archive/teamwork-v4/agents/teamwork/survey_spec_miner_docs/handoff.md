## 4. Edge Cases

| # | Feature | Input / Scenario | Observed / Specified Behavior |
|---|---|---|---|
| **1** | Spotify Importer (`spotify.py`) | `my_spotify_data.zip` filename collision between *Account Data* and *Extended Streaming History* | Both packages share the same ZIP filename; parser MUST inspect inner JSON filenames/keys (`Streaming_History_Audio_*.json` with `ts`/`ms_played` vs `StreamingHistory_music_*.json` with `msPlayed`) rather than relying on ZIP name. |
| **2** | Spotify Importer (`spotify.py`) | Podcasts & audiobooks inside `Streaming_History_Audio_*.json` | Records with `spotify_track_uri == null` (having `episode_name`/`spotify_episode_uri` or audiobook fields) MUST be strictly excluded from `play_events`. |
| **3** | Spotify Importer (`spotify.py`) | Historical `skipped` bug (2015-04-13 to 2022-10-16) | During this period Spotify did not record early skips in boolean `skipped`; parser MUST infer skips via `ms_played < 30_000` / `reason_end` (`fwdbtn`/`endplay`) rather than trusting `skipped: false/null`. |
| **4** | Spotify Importer (`spotify.py`) | Pre-2017 legacy `reason_start`/`reason_end` values (`clickside`, `popup`, `uriopen`) & `offline_timestamp` overlaps (~2.6%) | Accept legacy reasons cleanly without enum errors; normalize `offline_timestamp` (which Spotify logged in seconds in some periods and milliseconds in others) and avoid corrupting session timelines or double-counting overlapping offline plays. |
| **5** | Spotify Importer (`spotify.py`) | `incognito_mode: true` plays | Preserved in archive; expose flag for `capabilities.has_incognito_flag` and allow user-selectable filtering at import time (`exclude_incognito`) and in analytics. |
| **6** | YouTube Music Importer (`youtube.py`) | Non-music YouTube videos in `watch-history.json` | Strictly keep only entries where `entry.get("header") == "YouTube Music"`. |
| **7** | YouTube Music Importer (`youtube.py`) | Multilingual Google account prefixes & `" - Topic"` channel suffix | Do NOT hardcode English `"Watched "` only; strip localized prefixes dynamically (e.g., `"Watched "`, `"Vous avez regardé "`, `"Angesehen: "`, `"Viste "`, etc.) and strip `" - Topic"` from `subtitles[0]["name"]`. |
| **8** | YouTube Music Importer (`youtube.py`) | Deleted / private videos in Takeout JSON (`subtitles` key missing) | Must NOT raise `KeyError`/`IndexError`; gracefully skip unidentifiable deleted entries or mark fallback artist without crashing batch import. |
| **9** | YouTube Music Importer (`youtube.py`) | HTML Takeout file uploaded instead of JSON | Detect HTML content and return clear French HTTP 400 instructing user to switch Google Takeout "Formats multiples" from HTML (default) to JSON. |

| **12** | Deezer Importer (`deezer.py`) | Missing durations coded as `-1` (common on Deezer web player) | Never store `-1` as `play_duration_ms`; impute via bounded gap to next chronological play (capped to reasonable track length) or canonical track duration, setting `duration_is_estimated = 1`. |

| **14** | TIDAL Importer (`tidal.py`) | Unstandardized GDPR CSV headers, UTF-8 BOM, mixed duration formats | Strip UTF-8 BOM (`utf-8-sig`), auto-detect common aliases (`Title`/`Track Name`, `Artist`/`Artist Name(s)`, `Album`, `Duration`, `ISRC`), parse `MM:SS` / seconds / ms durations, and return `needs_mapping: true` + `detected_headers` for assisted UI mapping if required columns are ambiguous. |
